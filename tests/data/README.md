# Regression baselines

The JSON files contain CSV outputs and expected output filenames captured from
the original, unsplit MATE script before the module refactor, on inputs generated by
`make_inputs` in `tests/conftest.py`. They cover reference-aware trajectories,
continuous PCHIP trajectories with replicate bootstrapping, and reference-free
pseudotime with linear interpolation. Both continuous cases include joint PCA.

The original script was run with its unchanged `gizmos.import_from_sql` function
loaded on its own, because the unrelated RDKit imports in `gizmos.py` were not
available in the test environment. SQLite table selection and reading therefore
still used the original implementation when recording these results.

Tests compare every captured CSV with floating-point tolerances and check output
filenames and generated plots. These small synthetic inputs do not replace
validation on a real biological dataset. UMAP is optional and is not part of
these regression baselines.

Keep these baselines fixed when changing file organization. Update them only
when an intentional analysis change has been reviewed.
